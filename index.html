What is this?

A fan-made tool for Inscryption's Kaycee's Mod. It lets you choose which cards your run begins with — and, if you want, change their power, health, cost and sigils — then puts that deck into your game's save file. You do not need to install anything or understand how save files work.

What is a custom starting deck?

Normally Kaycee's Mod deals you one of a few fixed starter hands. This tool lets you pick any starter deck you like instead, so you can try a theme, a challenge, or just a hand you think is fun — without playing for hours to unlock it.

How to use it — the short way

  1. Start a Kaycee's Mod run first

    Open Inscryption, start Kaycee's Mod, pick your challenges and a starter deck, and as soon as the run begins, quit to the main menu (do not end the run). The deck you are about to change only exists once a run has been created. Leave the game closed while you work.

  2. Build your deck here

    In the builder, pick a ready-made deck from the shelf, or add cards from the catalogue one by one. Click a card on your board to change its stats or sigils. You never see any JSON.

  3. Patch your save file

    In the Save step, choose your SaveFile.gwsave. The page rewrites just your Kaycee's Mod deck and hands the file back to you to download. Everything happens in your browser — nothing is uploaded anywhere.

  4. Put the file back and play

    Replace the SaveFile.gwsave in your game folder with the downloaded one (your browser may rename it — rename it back to SaveFile.gwsave). Then open the game and continue your run. Your new deck is there.

Where is the save file? It is in the game's install folder, not Documents. On Steam: right-click Inscryption → Manage → Browse local files, and look for SaveFile.gwsave. There is also a SaveFile-Backup.gwsave that the game writes itself — leave that one alone.
If something goes wrong — the run will not load, or the deck looks broken — close the game and put your backup copy of SaveFile.gwsave back in the folder. That returns everything to how it was. This is why the backup at the top of this guide matters.

Editing the save by hand

Back up the save file first. A single missing comma or bracket will stop the file loading, and the only clean fix is putting the backup back.

  1. Find the save file

    It lives in the game's install folder, not in Documents. On Steam: right-click Inscryption → Manage → Browse local files. The path is usually something like …\steamapps\common\Inscryption.

    The file you want is SaveFile.gwsave. There is also a SaveFile-Backup.gwsave the game writes itself — leave that one alone.

  2. Open it as JSON

    Despite the extension, it is plain text laid out like JSON — not strictly valid JSON, since a few values are written without quotes, so some JSON tools will complain while plain text editors won't. Notepad works. Notepad++ or VS Code is much better, because you can set the language to JSON and collapse sections — the file is thousands of lines long.

  3. Start a Kaycee's Mod run, then quit to the main menu

    The deck you are about to edit only exists once a run has been created. So: open Kaycee's Mod, pick your challenges and starter deck, and as soon as the run begins, quit to the main menu. Leave the game closed while you edit.

    Quit to menu — don't end the run. Deliberately ending a run in the first area is what triggers the anti-reset-scumming rule, where one of your Rabbit Pelts is replaced with an Opossum, and then a Ring Worm on the next abandon. Quitting to the menu mid-run does not do that.

  4. Find the right deck — there are two of them

    Search for playerDeck. You will get more than one hit, because the file holds the base Act I game and Kaycee's Mod side by side: 

    // the FIRST one — this is the normal Act I story run. Not this one.
"currentRun": { … "playerDeck": { … } }

// the one you want — nested under ascensionData
"ascensionData": {
  "currentRun": {
    "playerDeck": {
      "cardIds": { … }        ← edit this

    Quickest way to be sure: search for ascensionData first, then search downward from there for playerDeck.

  5. Replace the card list

    Inside cardIds you will find "$rlength" (how many cards) and "$rcontent" (the list of internal card names). Paste in your new list and make the number match. 

    "cardIds": {
  "$id": 1234,          ← leave your own numbers alone
  "$type": 8,
  "$rlength": 3,        ← must equal the number of entries below
  "$rcontent": [
    "Stoat",
    "Bullfrog",
    "Wolf"
  ]
},

    If $rlength is smaller than the list, the extra cards are silently dropped. If it is larger, the game can crash. Keep the $id and $type values that are already in your file — they are file-specific.

    The forge below writes this block for you.

  6. Save, launch, continue

    Save the file with the same name. If you are using Notepad, use Save As, set the file type to All Files, and type the full name SaveFile.gwsave so it doesn't become SaveFile.gwsave.txt.

    Open the game and continue your Kaycee's Mod run. Your new cards are in the deck.

  7. Want custom power, health, cost or sigils too? Do this extra pass

    Stats and sigils live in a second block, cardIdModInfos, in the same playerDeck. On a fresh run most cards have an empty modification record, which is awkward to fill in by hand.

    The reliable trick is to make the game write the records for you: start the run with the Annoying Starters challenge enabled. That challenge stamps the Annoying sigil (ID 76) onto every starting card, so each card gets a complete, correctly-typed modification record. Then you just change the numbers inside it. 

    "cardIdModInfos": {
  …
  "$rcontent": [
    {
      "$k": "Wolf",              ← the card. 2nd copy = "Wolf#1", 3rd = "Wolf#2"
      "$v": { …
        "nameReplacement": "Fenrir",
        "attackAdjustment": 4,     ← added to base power
        "healthAdjustment": 3,     ← added to base health
        "abilities": {
          "$rlength": 2,
          "$rcontent": [ 24, 15 ]  ← sigil IDs (76 was Annoying)
        },
        "bloodCostAdjustment": -1,
        "bonesCostAdjustment": 0,
      … }
    }
  ]
}

    The adjustments are differences, not final values. A Wolf is 3/2, so attackAdjustment: 4 gives you a 7. The forge does that arithmetic and prints the exact field values per card.

Your save's type numbers

defaults from a sample save — open yours above to fill these in

These numbers differ from save to save. Open your save in Patch your save directly above and they are filled in for you. By hand: search your file for CardModificationInfo — the first hit spells out "N|DiskCardGame.CardModificationInfo, Assembly-CSharp" — put that N in the box, then do the same for the other five.

It must be higher than every $id already in your save — opening your save above fills it in. Carving more than one card counts up from here, each card using the next 7 numbers, so nothing collides even if you paste several at once.

Still the safer route: tab 2, editing a record the game already wrote (via the Annoying Starters trick), beats typing a brand-new one from scratch — fewer fields to get wrong. Use this tab when that isn't an option.

Warnings & limitations

what the save data does and does not allow
Back up your save file before making any changes. If a patched save will not load, putting your backup copy back returns everything to normal.

Some things are limited by what the game's save data actually allows. What is known today:

  • Only the Kaycee's Mod starting deck (Act I) is changed. The tool does not touch the normal Act I story run, Act II or Act III.
  • Cards from Act II and Act III can be added to the list, but many are uncastable or misbehave in Leshy's cabin. This has not been verified to work, so treat it as experimental.
  • Some sigils are built for one specific card or for a boss, and can break the game on an ordinary card. The builder marks these with a caution sign and lets you filter them out.
  • Sigil IDs above 106 are not defined. A negative final cost or final health can crash the game when the card is drawn — keep the totals sensible.
  • Kaycee's Mod nerfs some cards on purpose: Ouroboros resets to 1/1 every run, and Stoat is 1/2 rather than the story mode's 1/3.

About & links

The Carving Table is an unofficial, free fan tool that makes it easy to try custom starting decks in Kaycee's Mod — even if you have never touched JSON or a save file. It runs entirely in your browser as a static website.

  • Project author on GitHub — @NavidZareSWE
  • Found a bug, or a card or sigil that behaves oddly? Please open an issue on the project's GitHub repository so it can be looked into.
  • Like it? A star on the repository, or sharing it with another Kaycee's Mod player, is genuinely appreciated.

Credits & sources

Card faces and sigil glyphs are sliced out of the Inscryption card-list reference sheets, packed into two sprite-sheet image files that ship with this project. Forty sigils had a card carrying them alone, which is what made a clean cut possible. Most of the sigils seen in Act III — gems, conduits, batteries, latches and the rest — have icons hand-drawn for this page after the in-game ones, so they are recognisable without copying the art; Bomb Latch, Brittle Latch and Gem Spawn Conduit follow the look of their family rather than a picture of that exact icon. Anything still shown as a plain circular emblem has no reference art at all — that means "no picture", not a different kind of sigil.

Power, health, cost and printed sigils are taken from the reference sheets and cross-checked against the Inscryption Wiki's Act I table. Where the two disagreed the card's own printed face won: Beaver is 1/3, Skunk carries Stinky, and Amoeba carries Amorphous. Internal card file names and the sigil ID list are read out of jlcrochet's open-source save editor. Save-file structure, the modification-record shape and the Annoying Starters trick come from IceHippo's Steam guide and the Kaycee's Mod General Info site.
